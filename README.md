# 🧬 Primer Design Tool

A simple Python-based primer design and analysis tool that generates potential PCR primers from a target DNA sequence and evaluates basic primer properties.

This project is being developed as a **learning and portfolio project** alongside my biotechnology background. I have practical experience with molecular biology techniques and primer design, and I am using this project to improve my programming, bioinformatics, and computational biology skills.

> **Note:** I used AI tools as a learning and development assistant while building parts of this project. I am still learning Python and bioinformatics programming, so I am actively reviewing, testing, debugging, and improving the code rather than presenting it as entirely written from scratch.

---

## 🔬 What Does This Tool Do?

The tool takes a DNA sequence as input and generates potential **forward and reverse PCR primer candidates**.

It currently evaluates properties such as:

* Primer length
* GC percentage
* Melting temperature (Tm)
* Primer-binding coordinates
* Forward/reverse primer compatibility
* Expected PCR amplicon size
* Difference between forward and reverse primer Tm

Primer pairs are filtered according to user-defined parameters and ranked based on the difference between their melting temperatures.

## 🚀 Current Features

### Milestone 1 — Basic Sequence Analysis

* DNA sequence input
* FASTA header and whitespace cleaning
* DNA sequence validation
* Sequence length calculation
* GC percentage calculation
* Basic melting-temperature calculation

### Milestone 2 — Primer Candidate Generation

The tool can generate candidate:

* Forward primers
* Reverse primers

Users can control:

* Minimum primer length
* Maximum primer length
* Minimum GC%
* Maximum GC%
* Minimum Tm
* Maximum Tm

### Milestone 3 — Primer Pair Selection

The current version adds:

* Forward/reverse primer pairing
* Maximum allowed Tm difference
* Minimum amplicon size
* Maximum amplicon size
* Primer-binding coordinates
* Expected PCR product size
* Pair ranking
* Maximum number of pairs displayed

Primer pairs are currently ranked primarily by the smallest forward/reverse Tm difference.

## 🖥️ Example Workflow

1. Enter a DNA target sequence.
2. Set the desired primer parameters.
3. Generate forward and reverse candidates.
4. Set the desired PCR amplicon range.
5. Set the maximum acceptable Tm difference.
6. Generate compatible primer pairs.
7. Review the sequences, coordinates, Tm, GC%, and expected product size.

Example settings:

```text
Primer length:          18–25 bp
GC%:                    40–60%
Tm:                     57–63 °C
Amplicon size:          100–1000 bp
Maximum Tm difference:  3 °C
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/primer-design-tool.git
cd primer-design-tool
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

If PowerShell prevents activation, you can also run the project without activating the environment by using the appropriate Python executable.

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your browser.

## 🧪 Current Limitations

This project is **still under development**.

The current version does **not yet perform comprehensive primer quality or specificity analysis**.

Currently missing:

* Hairpin analysis
* Self-dimer analysis
* Forward/reverse cross-dimer analysis
* Genome/transcript specificity checking
* BLAST-based specificity analysis
* SNP awareness
* Secondary-structure scoring
* Advanced thermodynamic calculations
* Off-target analysis
* Automated primer optimization
* Experimental validation

Therefore, primers generated by this tool should **not be treated as experimentally validated primer designs**.

They should be considered candidate primers for educational and development purposes.
